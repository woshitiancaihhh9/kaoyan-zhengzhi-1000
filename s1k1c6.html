第 164 题单选

列宁根据他所处时代的实践曾指出，资本主义发展到垄断资本主义，进而发展到帝国主义，便具有其基本特征。这些基本特征中，在经济生活中起决定作用的是

  1. A．金融寡头
  2. B．资本家国际垄断同盟
  3. C．资本输出
  4. D．垄断组织
答案与解析

答案：D出处 · 精讲 P84 考点 79 -5-1

简析

列宁根据他所处时代的实践曾指出，资本主义发展到垄断资本主义，进而发展到帝国主义，便具有五个基本特征：1 垄断组织在经济生活中起决定作用；2 在金融资本的基础上形成金融寡头的统治；3资本输出有了特别重要的意义；4 瓜分世界的资本家国际垄断同盟已经形成；5最大资本主义大国已把世界上的领土瓜分完毕。这些特征集中体现了帝国主义的实质，即垄断资本凭借垄断地位，获取高额垄断利润。D 正确，A、B、C 错误。

核心背诵·命题点拨

考点出处 · 张修齐《小橙书》P85

· 帝国主义的特征: 垄断组织在经济生活中起决定作用; 在金融资本的基础上形成金融寡头的统治;资本输出有了特别重要的意义; 瓜分世界的资本家国际垄断同盟已经形成; 最大资本主义大国已把世界上的领土瓜分完毕。

在资本主义的自由竞争中，在剩余价值规律、竞争规律和资本积累规律的作用下，必然引起生产集中和资本集中，生产集中和资本集中发展到一定阶段必然引起垄断，这是资本主义发展的客观规律。资本集中是指

  1. A．国家政权和私人垄断资本融合在一起的过程
  2. B．大资本吞并小资本，或由许多小资本合并而成大资本的过程
  3. C．工业垄断资本和银行垄断资本融合在一起的过程
  4. D．个别资本通过剩余价值的资本化来增大资本的总量
答案与解析

答案：B出处 · 精讲 P79 考点 78 -2

简析

B 正确。国家垄断资本主义是国家政权和私人垄断资本融合在一起的垄断资本主义，A不符合题意。金融资本是由工业垄断资本和银行垄断资本融合在一起而形成的一种垄断资本。C 错误。D是指资本积聚。

① 资本集中的另一个解释：个别资本通过结合而形成较大的资本。

②注意资本积累、资本积聚与资本集中的区别。见《2027考研政治知识点精讲精练》第79页表格。

· 资本集中: 大资本吞并小资本, 或由许多小资本合并而成大资本的过程,其结果是越来越多的资本为少数大资本家所支配。

· 生产集中: 生产资料、劳动力和商品的生产日益集中于少数大企业的过程,其结果是大企业在整个社会生产中所占的比重不断增加。

金融资本是由工业垄断资本和银行垄断资本融合在一起而形成的一种垄断资本。金融资本的形成主要是通过

  1. A．金融联系、资本参与和人事参与
  2. B．参与制、个人联合、建立政策咨询机构
  3. C．生产集中、资本集中和金融联系
  4. D．人事参与、金融创新和金融自由化
答案与解析

答案：A出处 · 精讲 P80 考点 78 -5-1

简析

金融资本是由工业垄断资本和银行垄断资本融合在一起而形成的一种垄断资本。随着生产集中和垄断的发展，银行资本由集中走向垄断，工业垄断资本对银行的依赖增强，大银行同大企业的金融联系更加密切，形成了固定的关系。通过金融联系、资本参与和人事参与，银行垄断资本和工业垄断资本密切地融合在一起，产生了一种新型的垄断资本，即金融资本。A 正确。

点拨

金融自由化与金融创新是金融垄断资本得以形成和壮大的重要制度条件。

金融寡头是指操纵国民经济命脉，并在实际上控制国家政权的少数垄断资本家或垄断资本家集团。金融寡头在经济领域中的统治主要是通过"参与制"实现的。所谓"参与制"是指金融寡头

  1. A．通过把自己的代理人送进政府或议会来为其垄断统治服务
  2. B．通过建立政策咨询机构等方式参与政府的政策制定
  3. C．通过掌握一定数量的股票来层层控制企业
  4. D．私人与国家共同投资开办合营企业
答案与解析

答案：C出处 · 精讲 P80 考点 78 -5-2

简析

金融寡头在经济领域中的统治主要是通过"参与制"实现的。所谓"参与制"，即金融寡头通过掌握一定数量的股票来层层控制企业的制度。C正确。金融寡头对国家机器的控制，主要是通过同政府的"个人联合"来实现的。这种联合有多种途径，如金融寡头直接把自己的代理人送进政府或议会，通过掌握政权，利用政治力量为其垄断统治服务。A错误。金融寡头还通过建立政策咨询机构等方式对政府的政策施加影响。B错误。"国家和私人共同投资开办合营企业"是国家垄断资本主义的主要形式之一。D 错误。

第 169 题单选

垄断资本的实质在于获取垄断利润，垄断利润是垄断资本家凭借其在社会生产和流通中的垄断地位而获得的超过平均利润的高额利润。垄断利润的形成，关键在于

  1. A．垄断组织能够把包罗万象的社会生产全部包下来
  2. B．垄断消除了产生竞争的经济条件
  3. C．垄断条件下的竞争采取的完全是非经济的手段
  4. D．垄断组织在经济生活中起了决定性作用
答案与解析

答案：D出处 · 精讲 P80 考点 78 -6-1

简析

垄断资本的实质在于获取垄断利润，垄断利润是垄断资本家凭借其在社会生产和流通中的垄断地位而获得的超过平均利润的高额利润。垄断利润的形成，关键在于垄断组织在经济生活中起了决定性作用，从而阻碍了资本在各部门之间的自由转移，限制了利润平均化的趋势，这样一来，垄断资本家有可能长期获得大大超过平均利润的垄断利润。D 正确。

垄断是在自由竞争中形成的,是作为自由竞争的对立面产生的。但是,垄断并不能消除竞争,反而使竞争变得更加复杂和激烈。这是因为:1 垄断没有消除产生竞争的经济条件。2 垄断必须通过竞争来维持。3社会生产是复杂多样的,任何垄断组织都不可能把包罗万象的社会生产全部包下来。A、B错误。垄断条件下的竞争同自由竞争相比,具有一些新特点。在竞争手段上,自由竞争主要运用经济手段,如通过改进技术、提高劳动生产率、降低产品成本等以战胜对手,而垄断条件下的竞争除了采取各种形式的经济手段外,还采取非经济的手段,使竞争变得更加复杂、激烈。C 错误(并不是"完全"采取非经济的手段)。

  4. D．国际康采恩
答案与解析

答案：A出处 · 精讲 P83 考点 79 -4-2

简析

早期的国际垄断同盟的主要形式是国际卡特尔,其显著特点是它的活动主要是在流通领域,而不是一种直接的生产上的联合。国际托拉斯、国际康采恩也是早期的国际垄断同盟的形式,但不是主要形式。当代国际垄断同盟的主要形式是国家垄断资本主义的国际联盟，A 正确。

第 173 题单选

第二次世界大战后，由于多种社会因素的影响，资本主义发生了一系列变化。在劳资关系方面，劳动对资本的隶属从资本主义发展初期的形式上的隶属逐渐成为实质上的隶属。之所以发生这种变化，是因为

  1. A．资本家与雇佣工人的关系从"自由平等"变为人身依附
  2. B．终身雇佣和职工持股等方式使得劳动者成为资本家的代理人
  3. C．劳动者个人的技能不再对生产过程和结果具有决定意义
  4. D．雇佣劳动者的剩余劳动不再是剩余价值的唯一源泉
答案与解析

答案：C出处 · 精讲 P85 考点 81 拓展与点拨

简析

在资本主义条件下,劳动从进入生产过程开始,就已经隶属于资本,在表面平等的交换关系背后,是资本对劳动的实际支配和控制。在资本主义发展的初期,资本家指挥下的劳动只是形式上隶属于资本,随着机器大工业生产体系的建立和生产工具使用的社会化程度提高,劳动者个人的技能不再对生产过程和结果具有决定意义,劳动对资本的隶属就成为实质上的隶属。C 正确。

与以往的剥削制度不同,资本家与雇佣工人的关系不是完全占有,也不是人身依附,而是基于劳动者人身自由基础上的"平等"关系,剥削带有一定的隐蔽性。A错误。劳动者属于受剥削的阶级,不可能成为资本家或其代理人。而且终身雇佣和职工持股也只是让工人产生归属感,从而更加自觉地服从资本家的统治,与题目所问的劳动对资本的实质上的隶属不相符。B错误。雇佣劳动者的剩余劳动是剩余价值的唯一源泉。即使是在生产自动化条件下,雇佣工人的剩余劳动仍然是这种剩余价值的唯一源泉。D错误。

核心背诵·命题点拨

考点出处 · 张修齐《小橙书》P87

· 在资本主义发展的初期, 资本家指挥下的劳动只是形式上隶属于资本, 随着机器大工业生产体系的建立和生产工具使用的社会化程度提高, 劳动者个人的技能不再对生产过程和结果具有决定意义,劳动对资本的隶属就成为实质上的隶属。
