第 43 题考点拓展题多选

习近平提出，发展新质生产力是推动高质量发展的内在要求和重要着力点。关于新质生产力，以下理解正确的有

  1. A．战略性新兴产业、未来产业是发展新质生产力的主阵地
  2. B．传统产业通过转型升级，也能成为新质生产力的重要部分
  3. C．科技创新是发展新质生产力的核心要素
  4. D．发展新质生产力以劳动者、劳动资料、劳动对象及其优化组合的跃升为核心标志
答案与解析

答案：ABC

简析

站在新的起点上,必须围绕发展新质生产力布局产业链,完善现代化产业体系。一方面,战略性新兴产业、未来产业是发展新质生产力的主阵地,要打造生物制造、商业航天、低空经济等战略性新兴产业,开辟量子、生命科学等未来产业新赛道;另一方面,传统产业通过转型升级,也能成为新质生产力的重要部分,要让数智技术、绿色技术得到更广泛应用,推动产业向中高端迈进,跑出新旧动能转换"加速度"。A、B正确。科技创新能够催生新产业、新模式、新动能,是发展新质生产力的核心要素。C正确。

新质生产力以劳动者、劳动资料、劳动对象及其优化组合的跃升为基本内涵，以全要素生产率大幅提升为核心标志。D 错误。

点拨

关于新质生产力的主阵地，有多个提法：

①支柱产业是发展新质生产力的主阵地。

(习近平2024年4月在重庆考察时指出)

②战略性新兴产业、未来产业，是构建现代化产业体系的关键，是发展新质生产力的主阵地。

③战略性新兴产业知识技术密集、成长潜力大、综合效益好，对经济社会全局和长远发展具有引领带动作用，是形成新质生产力的主阵地。

第 44 题时政储备题多选

习近平指出，新质生产力"以全要素生产率大幅提升为核心标志，特点是创新，关键在质优，本质是先进生产力"。这告诉我们，理解新质生产力，一个重要视角是全要素生产率。然而，全要素生产率增长不足是全球性挑战。例如，美国最近20年全要素生产率年均增速只有约$0.7\%$ ，英国、法国、德国等工业化国家的全要素生产率增速也都陆续降到 $1\%$以内。相较于其他工业化国家，我国在提升全要素生产率增速方面有许多有利因素。这些有利因素包括

  1. A．我国不缺乏提升全要素生产率所需的大规模生产场景、技术创新和模式创新的应用场景
  2. B．我国超大规模市场的优势已经形成，经济始终保持高速增长
  3. C．我国拥有数字化和绿色化发展所带来的巨大生产率增长空间
  4. D．我国进一步全面深化改革将形成一个庞大的制度红利空间，带来资源配置效率提升的巨大可能
答案与解析

答案：ACD

简析

市场是最稀缺的资源,超大规模市场是我国的优势所在。相较于其他工业化国家,我国在提升全要素生产率增速方面有许多有利因素。①我国制造业增加值的 GDP 占比约为 27%, 制造业增加值占全球比重约为30%。我国不缺乏提升全要素生产率所需的大规模生产场景、技术创新和模式创新的应用场景。②我国拥有数字化和绿色化发展所带来的巨大生产率增长空间。与美国旨在提高制造业增加值占比的"再工业化"不同,我国数字化和绿色化发展的意涵是所有行业可以通过数字化转型和能源转型实现再次增长。③进一步全面深化改革将形成一个庞大的制度红利空间, 带来资源配置效率提升的巨大可能,进一步拉动全要素生产率的增长。A、C、D 正确。我国经济已由高速增长阶段转向高质量发展阶段,B 错误。

第 50 题时政储备题多选

纵深推进全国统一大市场建设，基本要求是"五统一、一开放"，即统一市场基础制度、统一市场基础设施、统一政府行为尺度、统一市场监管执法、统一要素资源市场，持续扩大对内对外开放。在"五统一、一开放"中，"统一政府行为尺度"的首次提出，意义重大。"统一政府行为尺度"有助于

  1. A．促进要素资源流动
  2. B．破解不同地区之间的过度"内卷"
  3. C．从根本上杜绝权力寻租和腐败行为
  4. D．为各类经营主体创造更公平的市场竞争环境
答案与解析

答案：ABD

简析

在"五统一、一开放"中，"统一政府行为尺度"的首次提出，意义重大。这一要求为政府行为厘清了边界、明确了尺度。"统一政府行为尺度"有助于为各类经营主体创造更公平的市场竞争环境，破解不同地区之间的过度"内卷"，促进要素资源流动。A、B、D正确。反腐败斗争是一项长期、复杂、系统的工程，需要综合运用法治、监督、教育等多种手段。"统一行为尺度"作为一项重要的制度性建设，是"治本之策"的重要一环，但将其作用拔高到"从根本上杜绝"权力寻租和腐败行为的程度，则忽略了问题的复杂性。C错误。

第 52 题时政储备题多选

内需是拉动经济增长的主动力和稳定锚。习近平强调，"要积极扩大国内需求"，"创造更多消费场景，持续释放消费和投资潜力"。扩大内需不是权宜之计，而是战略之举，这是因为

  1. A．大国经济的特征都是内需为主导、内部可循环
  2. B．扩大内需是应对外部冲击的有效途径
  3. C．扩大内需是全面建设社会主义现代化国家的实践要求
  4. D．扩大内需是满足人民对美好生活向往的现实需要
答案与解析

答案：ABCD

简析

当前,我国面临的国际环境复杂严峻,国内需求不足的挑战仍然较大。扩大内需不是权宜之计,而是战略之举。着力扩大国内需求,是当前和今后一段时间经济工作的重要任务。看普遍规律,内需主导是大国经济特征。从国际经验看,大国经济的特征都是内需为主导、内部可循环。看外部环境,扩大内需是应对外部冲击的有效途径。看国内现实,扩大内需是全面建设社会主义现代化国家的实践要求。看百姓需求,扩大内需是满足人民对美好生活向往的现实需要。A、B、C、D 全选。

第 56 题考点拓展题多选

区域重大战略的深入实施，充分考虑了我国类型多样的国土空间格局，对推动区域经济发展具有重要的指引作用；区域重大战略的协同联动，不仅为我国区域经济发展提供了新路径，形成了具有中国特色的区域融合发展方式，也推动了区域发展理论创新，为全球区域发展理论创新作出了独特贡献。实施区域重大战略，有助于

  1. A．打造高质量发展的动力源
  2. B．推动所有地区同时达到一个富裕水准
  3. C．加强生态文明建设
  4. D．建设改革开放的试验田
答案与解析

答案：ACD

简析

实施区域重大战略,有助于打造高质量发展的动力源。比如,京津冀协同发展围绕疏解北京非首都功能,把发展落差的势能变成协同发展的动能,推动北京"新两翼"协同发力,带动周边区域高质量发展。实施区域重大战略,有助于加强生态文明建设。比如,长江经济带高质量发展坚持生态优先、绿色发展,共抓大保护、不搞大开发,扎实推进长江生态环境保护修复。实施区域重大战略,有助于建设改革开放的试验田。比如,粤港澳大湾区建设要求在"一国两制"方针和基本法框架内,发挥粤港澳三地综合优势,加强规则衔接、机制对接,推动港澳融入国家发展大局,对接高质量共建"一带一路",建设高水平开放合作平台。A、C、D 正确。

共同富裕是全体人民共同富裕,是人民群众物质生活和精神生活都富裕,不是少数人的富裕,也不是整齐划一的平均主义;不是所有人都同时富裕,也不是所有地区同时达到一个富裕水准。B 错误。
